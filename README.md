# Simple Linear Regression – Marketing ROI Analysis

## Project Overview
This project analyzes the relationship between advertising expenditure
and sales using Simple Linear Regression with Python and statsmodels.

## Dataset Features
- TV
- Radio
- Social_Media
- Sales

## Objectives
- Load and clean dataset
- Perform Exploratory Data Analysis (EDA)
- Identify most correlated variable
- Build OLS Regression Model
- Validate regression assumptions
- Interpret statistical outputs
- Recommend best ROI marketing channel

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- statsmodels
- scipy

## Installation

pip install pandas numpy matplotlib seaborn statsmodels scipy

## Files Included
- regression_analysis.ipynb
- marketing_dataset.csv
- README.md

## Conclusion
TV advertising showed the strongest positive relationship with Sales
and delivered the best ROI performance.
